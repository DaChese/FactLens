Install FactLens for Chrome

The prototype is distributed as an unpacked extension while Chrome Web Store review is pending. The package is preconfigured for the Railway-hosted FactLens service.

FactLens extension · version 1.8.0

Download the current build

Chrome requires developer mode for prototypes distributed outside its store. The browser will always ask you to confirm the unpacked extension.

Download extension package

ZIP archive · Manifest V3 · Windows, macOS, Linux, and ChromeOS

  1. 1

    Extract the download

    Unzip factlens-extension.zip into a folder you will keep.

  2. 2

    Open extensions

    Navigate to chrome://extensions and enable Developer mode.

  3. 3

    Load FactLens

    Select Load unpacked, then choose the extracted extension folder.

  4. 4

    Pin and start

    Pin FactLens, open a supported news video, and select the extension to begin.

Why is there no silent installer?

Chrome blocks websites from silently installing unpacked extensions. This guided flow preserves Chrome’s required confirmation and makes every requested permission visible.
