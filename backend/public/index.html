Methodology

What the studio does

FactLens identifies the story, compares other outlet coverage, and extracts missing context only when the story match is strong enough.

Statement checks and public reaction are separate, on-demand steps. Public discussion is not treated as verified reporting.

The browser studio does not store transcripts, capture audio, inspect another tab, or expose Railway environment variables to the page.
